# Glossaire FR → AR (MaisDot, arabe standard moderne)

Conventions : sigles français et OTAN laissés en caractères latins (MEDOT, MA, ME, MAG, TCIDR, GTIA, BIA, FRAGO…), souvent précédés de l'article « الـ » (ex. « الـ MA »). GDH (« J+1 04h00 »), `{n}`, symboles et noms propres de l'exemple fictif (Morlac, Sarve, Vernes, Saint-Ivre, Lune, Quatre-Vents, Kardestan, Valdor) inchangés. « p. 23 » → « ص 23 ». Adresse directe : impératif masculin singulier neutre (« اكتب »، « انتقل »). Les « ? » finaux sont rendus par le point d'interrogation arabe « ؟ » ; les autres ponctuations de début et de fin sont conservées.

## Choix douteux à faire relire

1. **« clé » → « المفتاحية »** (zone, point, moment) : choisi pour rester distinct de « الحاسم » (décisif). Les armées arabes emploient souvent « الأرض الحيوية / الحاكمة » pour *key terrain* ; à valider.
2. **impératif → « الشرط الحتمي »** : pas d'équivalent normalisé ; alternative possible « الضرورة الحتمية ».
3. **articulation et modelage → tous deux « التشكيل »** : risque de confusion (articulation = *task organisation*, modelage = *shaping*). Envisager « تنظيم القوة » pour l'articulation.
4. **recueil → « استقبال القوات المنسحبة » / « الاستقبال »** : terme technique sans équivalent arabe fixe ; « التلقّف » ou « الاستيعاب » sont aussi rencontrés.
5. **réunion → « إيجاز »** (briefing) plutôt que « اجتماع » ; **présupposition / hypothèse → « الافتراض / الفرضية »**, distinction ténue en arabe.
6. **Locale d'affichage (id 1150)** : « fr-FR » remplacé par « ar-u-nu-latn » (arabe avec chiffres latins, cohérent avec les GDH). À vérifier avec le code.
7. **Fragment 1318 / 1320-1321** : « بلا إجابة س » + « تُحتسب خاطئة » pour former « ستُحتسب » par concaténation ; à vérifier à l'affichage.
8. **Mise en page RTL** : les flèches → et les fragments mêlant code et texte sont conservés tels quels ; un contrôle visuel en sens droite-à-gauche est nécessaire.
9. **foudroyance → « السرعة الصاعقة »**, **modularité → « المرونة التركيبية »** (facteurs de succès RFT 3.2.1) : traductions descriptives.
